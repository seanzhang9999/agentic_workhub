# Personal Workhub interaction demo

Three demonstration screens: personal workspace, document background, and continuation handoff preview.

Open `index.html` in a browser. The exported page is self-contained and uses a sandboxed frame. All example data is fictional. There are no account connections, document writes, or agent messages. This is not the running MCP gateway or local Feishu viewer.

Only this `site/` directory is published by `.github/workflows/pages.yml`. Runtime configuration and private collection data are never included.
